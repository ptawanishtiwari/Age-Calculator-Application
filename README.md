# 🎂 Age Calculator Application

A **minimalistic and highly responsive web application** that calculates a user’s exact age in **years, months, and days** based on their date of birth.  
The application is designed with a clean UI and works seamlessly across mobile, tablet, and desktop devices.

Visit the live link to see the application in action:

## ✨ Features

- 📅 User-friendly date picker for selecting date of birth  
- 🧮 Accurate age calculation (Years, Months, Days)  
- 📱 Fully responsive design (mobile-first)  
- 🎨 Minimal and clean UI  
- ⚡ Fast and lightweight (no backend required)

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the application  
- **CSS3** – Styling and layout  
- **Bootstrap 5** – Responsive design  
- **JavaScript** – Age calculation logic  

---

## 🧠 How It Works

1. User selects their **Date of Birth**
2. JavaScript compares DOB with the **current system date**
3. The application calculates:
   - Years
   - Months
   - Days
4. Result is displayed instantly on the screen
